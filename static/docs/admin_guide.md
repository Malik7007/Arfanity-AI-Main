# Arfanity AI - Administrator Guide

As an administrator of **Arfanity AI**, you have full control over the platform's users, models, and system configuration. This guide outlines your primary responsibilities and tools.

## 🛡️ Accessing the Admin Panel

To access the administrative interface, click on your profile picture in the sidebar and select **"Admin Panel"**. This option is only visible to users with the **Admin** role.

## 👥 User Management

### Approving New Users
By default, new signups may require approval. In the **Users** tab, you can:
- **Approve**: Grant access to pending users.
- **Change Role**: Promote users to Admins or demote them.
- **Delete/Suspend**: Remove access for specific users.

### Permissions
Configure what regular users can do:
- Enable/Disable chat sharing.
- Grant access to specific models.
- Control access to features like Web Search or Image Generation.

## 🤖 Model Management

### Connecting Engines
Arfanity AI can connect to various backends:
- **Ollama**: For local models.
- **OpenAI**: For GPT models.
- **Custom APIs**: Connect any OpenAI-compatible API.

### Pinned Models
You can set default models that appear for all users to ensure consistency across your organization.

## ⚙️ System Configuration

### Branding
Customize the application appearance:
- Change the site title and logo.
- Set a custom splash screen.
- Define the default UI theme.

### Authentication
Configure how users log in:
- Enable/Disable email signups.
- Set up OAuth (Google, Microsoft, GitHub, etc.) for Single Sign-On (SSO).
- Manage LDAP connections for enterprise directories.

## 📊 Monitoring and Security

### Audit Logs
Track system activity to ensure compliance and security. View who accessed which models and when.

### Usage Statistics
Monitor the load on your AI engines and track the number of active users and conversations.
