# Arfanity AI - User Guide

Welcome to **Arfanity AI**, your premium AI interface for seamless interaction with the world's most advanced language models. This guide will help you navigate and master the features of the platform.

## 🚀 Getting Started

### 1. Account Creation
If your administrator has enabled signups, you can create an account on the login page. Once registered, you may need to wait for administrator approval before you can start chatting.

### 2. Starting Your First Chat
- Click on the **"New Chat"** button in the sidebar or the central logo.
- Select a model from the dropdown menu at the top.
- Type your message in the chat box at the bottom and press Enter.

## 🛠️ Key Features

### Model Selection
Arfanity AI supports multiple models (like GPT-4, Llama 3, Claude, etc.). You can switch between them using the selector at the top of the chat window.

### Image Generation
If enabled, you can generate images by describing what you want to see. Arfanity AI will use its internal engines to bring your imagination to life.

### Web Search
Need real-time information? Enable **Web Search** in the chat controls to allow the AI to browse the internet for the most up-to-date answers.

### File Analysis
Upload documents (PDF, Docx, TXT, etc.) or images by clicking the **"+"** button or dragging them into the chat. The AI can summarize, analyze, and answer questions about your files.

### Code Interpreter
Run Python code directly within the chat for data analysis, math, or visualization. The AI will execute the code and show you the results instantly.

## 📁 Managing Your Chats

- **Sidebar**: Access your chat history from the left sidebar.
- **Pinning**: Keep important chats at the top for easy access.
- **Folders**: Organize your chats into folders.
- **Archiving**: Hide old chats without deleting them.
- **Exporting**: Download your conversations in JSON, TXT, or PDF formats.

## ⚙️ Settings
Click on your profile picture in the sidebar to access **Settings**. Here you can:
- Change the theme (Light/Dark/System).
- Set your preferred language.
- Customize chat behavior (Temperature, Top-K, etc.).
- Manage your API keys if allowed.
